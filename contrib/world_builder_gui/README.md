# GWB Visual Builder

A dependency-free browser prototype for visually composing Geodynamic World
Builder models. It keeps the `.wb` JSON and `gwb-grid` `.grid` configuration in
sync while features are positioned and configured.

## Run

```bash
npm start
```

Then open <http://127.0.0.1:4173>.

## Test

```bash
npm test
```

The prototype supports:

- Cartesian and spherical-chunk grid setup with mesh resolution.
- Clicking or dragging continental plates, oceanic plates, subducting plates,
  faults, mantle layers, and plumes onto a 2D workspace.
- A shape editor with point-by-point and freehand drawing, straight or smooth
  geometry, arbitrary vertex addition/removal, direction reversal, and
  draggable control points. Double-clicking an edge inserts another vertex;
  there is no vertex limit.
- Moving features and connecting their nearest boundaries.
- Visible, draggable dip-direction handles and dip-angle labels for
  subducting plates and faults.
- An optional plan-view slab projection with a shaded down-dip ribbon, depth
  contours, deep-edge arrow, and live updates from dip angle and segment length.
- Per-feature internal layers generated by count or edited as exact depth
  intervals, with independent composition and temperature values. Slabs and
  faults use their native distance-from-surface layer coordinates.
- Named continental (25 km upper crust, 15 km lower crust, 60 km mantle
  lithosphere) and oceanic (8 km crust, 72 km mantle lithosphere) presets.
- Adjustable PNG/JPEG/WebP reference maps with opacity, scale, translation,
  rotation, and editable Cartesian or longitude/latitude bounds.
- A SubMachine/ORFEUS tomography explorer that loads a selected model and depth
  slice as a georeferenced background and transfers the selected area into a
  3D spherical-chunk grid.
- A separate Topography workspace with mountain, rift, plateau, island, and
  Perlin-style procedural generators; elevate, depress, and smooth brushes;
  two-click selection uplift/depression; hillshade and opacity controls; NOAA
  ETOPO relief loading; ASCII grid, XYZ/CSV, JSON and grayscale-raster import;
  and editable XYZ export.
- An EarthByte/GPlates paleogeography workspace with explicit reconstruction
  model, age, and anchor-frame controls; reconstructed continent, subduction,
  and plate-boundary overlays; bundled Merdith 2021 geometry from
  `contrib/gplates`; conversion of visible vectors to simplified editable GWB
  features; and an editable, non-quantitative paleo-relief proxy. Published
  PaleoDEM elevation grids can be imported through the same topography tools.
- Feature-specific geometry, composition, and thermal controls.
- Plan, isometric 3D-volume, spherical-globe, and depth-section views with
  visible slab volumes, segment thickness, dip labels, and cursor
  depth/distance readouts.
- Geological-material and temperature rendering modes with kelvin labels,
  a configurable temperature scale, contours, surface shading, light strength,
  and persistent dark/light interface themes.
- Persistent camera controls for zooming, rotating, and resetting every model
  view, plus mouse-wheel zoom on the canvas.
- The official Geodynamic World Builder logo from the project documentation.
- Correct separation of surface X/Y or longitude/latitude from vertical depth;
  spherical chunk grids convert editor depth bounds to native radial bounds.
- Drawing cross sections directly on the plan view.
- A searchable library generated from the official tutorials, cookbooks, and
  tested reference models.
- Lossless import and re-export of advanced World Builder parameters.
- An advanced per-feature JSON editor for parameters not yet represented by a
  dedicated graphical control.
- Live `.wb` JSON and `.grid` generation, import, export, and local autosave.

The implementation deliberately uses browser-native Canvas for the current
editable plan view and lightweight 3D/section previews. A Three.js/WebGL
renderer can replace the 3D drawing layer later without changing the project
model or generators in `core.js`.

The tomography bridge requests public SubMachine depth-slice rasters through
the local Node server. It validates the model and numeric bounds and retains
the source result URL as metadata. Volumetric cubes and numeric cross-sections
remain a separate data/import workflow.

The paleogeography bridge requests GeoJSON from the public GPlates Web Service
through validated server-side endpoints. Remote geometries are kept in the
current browser session instead of local storage because global reconstructions
can contain thousands of features.
